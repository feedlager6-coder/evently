### Возможности встроенного нативного CSS:
- **Размытие и матирование:** Нативный `backdrop-filter: blur(...)` и `-webkit-backdrop-filter: blur(...)` поддерживаются всеми современными мобильными браузерами и Telegram WebKit.
- **Световые блики (Specular Highlights):** Реализуются через многослойные `box-shadow: inset 0 1px 1px 0 rgba(255, 255, 255, 0.12)` без единого килобайта стороннего кода.
- **Градиентные границы:** Нативные CSS-свойства `border` с цветовыми альфа-каналами `rgba(255, 255, 255, 0.08)`.
- **Микроанимации:** CSS Transitions на GPU-свойствах (`transform`, `opacity`) с кривыми `cubic-bezier(0.16, 1, 0.3, 1)`.

> [!NOTE]
> **Решение по зависимостям:** **0 новых npm-пакетов.** Вся эстетика Liquid Glass и тактильные микроинтеракции полностью реализуются нативными возможностями CSS и установленного Tailwind CSS v4. Ни GSAP, ни Three.js в `package.json` не добавляются. Бандл приложения не увеличивается.

## 5. Механизм переключения интерфейса (Feature Flag / CSS Theme Scoping)

Для обеспечения 100% сохранности оригинального дизайна без удаления существующих стилей:

1. **Неразрушающее расширение `index.css`:**
   - Все оригинальные стили (`.glass-panel`, `.card-press`, `--bg-elevated` и т.д.) остаются нетронутыми.
   - Новые стили Liquid Glass изолируются под скоуп селектора темы:
     ```css
     /* Экспериментальные стили активируются ТОЛЬКО при наличии атрибута темы */
     [data-theme="liquid-glass"] {
       --glass-surface-base: rgba(19, 23, 34, 0.78);
       --glass-surface-elevated: rgba(25, 30, 46, 0.82);
       --glass-specular-subtle: inset 0 1px 1px 0 rgba(255, 255, 255, 0.12);
       /* ... */
     }
     ```
2. **Бесшовное переключение в рантайме:**
   - Атрибут `data-theme="liquid-glass"` может активироваться через:
     - Параметр URL: `?theme=liquid-glass`
     - Локальное хранилище: `localStorage.getItem('theme') === 'liquid-glass'`
     - Переключатель в профиле / дебаг-панели.
   - Если атрибут не задан, приложение работает в **100% оригинальном визуальном режиме**.
   - Переключение между исходным и новым дизайном происходит мгновенно, без пересборки и без переключения веток.
