# Evently — Telegram-First Event Discovery Platform

**Evently** — это Telegram-first платформа для поиска, создания и посещения городских мероприятий в Telegram, использующая возможности Telegram Bot API, Inline Queries и Telegram Mini Apps.

---

## 🌟 Ключевая концепция

Пользователь находится в любом групповом или личном чате Telegram и напрямую вызывает бота через инлайн-режим:
```text
@evently концерты в Варшаве
@evently спорт в Махачкале
@evently выставки на выходных
```

Бот мгновенно возвращает карточки релевантных событий с кнопкой перехода в **Telegram Mini App**, где доступны:
- Выбор города (**Варшава**, **Махачкала**, **Москва**) с фильтрацией по локальным часовым поясам.
- Быстрые фильтры дат (**Все даты**, **Сегодня**, **Завтра**, **Выходные**).
- Фильтры по категориям (**Концерты**, **Вечеринки**, **Спорт**, **Образование**, **Бизнес**, **Выставки**, **Другое**).
- Просмотр карточек и детальной информации о мероприятии.
- Идемпотентная регистрация **«Я иду»** $\leftrightarrow$ **«✓ Вы идёте»** с тактильным откликом (Telegram Haptic Feedback).
- Кабинет организатора (**«Создать мероприятие»**) с отправкой на модерацию.
- Панель администратора для проверки, одобрения (**Опубликовать**) и отклонения (**Отклонить с причиной**) событий.

---

## 🛠️ Архитектура

- **Backend**: Python 3.13, FastAPI, SQLAlchemy 2.0 (Async), SQLite WAL (`aiosqlite`).
- **Telegram Auth**: Строгая криптографическая проверка `initData` по HMAC-SHA256 (`compare_digest`, проверка `auth_date <= 86400s`, автосинхронизация пользователей).
- **Inline Query Parser**: Детерминированный Regex-парсер городов, категорий и дат без внешних LLM-задержек.
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Telegram WebApp SDK (`telegram-web-app.js`).
- **TypeSafe AI Integration**: Изолированный опциональный сервис вторичной валидации контента с таймаутом 1 сек. и fallback-детерминированным режимом. Секретный ключ хранится строго в `.env` и никогда не передаётся во фронтенд или Git.

## 🚀 Быстрый старт

### 1. Настройка окружения
Скопируйте пример файла переменных окружения:
```bash
cp .env.example .env
```
Заполните параметры в `.env`:
- `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота (от @BotFather).
- `TELEGRAM_MINI_APP_URL` — ссылка на Telegram Mini App (например, `https://t.me/evently_bot/app`).
- `ADMIN_USER_IDS` — Telegram ID администраторов через запятую (например, `123456789`).
- `TYPESAFE_API_KEY` — (опционально) API-ключ TypeSafe AI.

### 2. Запуск Backend
```bash
# Установка зависимостей (при необходимости)
pip install -r backend/requirements.txt # или виртуальное окружение

# Запуск FastAPI с автоперезагрузкой
uvicorn backend.app.main:app --reload --port 8000
```
API будет доступно по адресу: `http://127.0.0.1:8000`
Документация Swagger: `http://127.0.0.1:8000/docs`

При первом запуске база данных SQLite инициализируется автоматически и наполняется 30 демонстрационными событиями для Варшавы, Махачкалы и Москвы.

### 3. Сборка и запуск Frontend
```bash
cd frontend

# Установка зависимостей
npm install

# Режим разработки
npm run dev

# Продакшн-сборка в frontend/dist
npm run build
```
После сборки (`npm run build`) FastAPI автоматически раздаёт готовый SPA-бандл по корневому адресу `/`.

## 🧪 Тестирование

Полный набор автоматизированных тестов включает 33 сценария:
- `tests/test_auth.py` — безопасность HMAC-SHA256, защита от подделки хэша и истечения сессии.
- `tests/test_parser.py` — детерминированный разбор городов, дат и категорий.
- `tests/test_events_and_rsvp.py` — жизненный цикл событий, видимость статусов и идемпотентность RSVP.
- `tests/test_moderation.py` — права администратора, модерация, отклонение с причиной.
- `tests/test_telegram_bot.py` — инлайн-запросы, команды `/start`, `/create`, `/admin`, вебхук.
- `tests/test_api_endpoints.py` — сквозные интеграционные тесты API и раздача статики SPA.
- `tests/test_typesafe.py` — изоляция и graceful fallback TypeSafe AI.

Запуск тестов:
```bash
pytest -v
```

## 🔒 Безопасность

1. Ключи и секреты (`.env`, `TYPESAFE_API_KEY`, `TELEGRAM_BOT_TOKEN`) внесены в `.gitignore` и исключены из репозитория.
2. Проверка Telegram `initData` выполняется в соответствии с официальной документацией Telegram Bot API.
3. Доступ к панели модератора защищён проверкой Telegram ID администратора.
